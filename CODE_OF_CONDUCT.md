# Código de conduta

Queremos uma comunidade curiosa, direta e acolhedora. Discorde de ideias com evidências; não ataque pessoas. Assédio, discriminação, exposição de dados pessoais e conteúdo malicioso não serão tolerados.

O humor ácido da personagem não é licença para crueldade. Moderadores podem remover contribuições e restringir participantes para proteger o projeto.
