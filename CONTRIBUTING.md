# Como contribuir

1. Abra uma Issue descrevendo o problema, proposta ou fonte.
2. Faça um fork e crie uma branch curta.
3. Mantenha a mudança focada e execute os testes relevantes.
4. Envie um Pull Request explicando mudança e verificação.

Dados precisam informar origem, autor quando conhecido, licença, idioma e transformações. Dados sem licença clara ou com informações pessoais não serão incorporados.

Correções linguísticas devem incluir entrada, saída observada e saída esperada. Mudanças de personalidade não devem introduzir ataques, discriminação ou sarcasmo direcionado a pessoas vulneráveis.

Nunca inclua `.env`, tokens, senhas, cookies, chaves privadas ou dumps de usuários.
