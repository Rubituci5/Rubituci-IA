# Segurança

Não publique vulnerabilidades, credenciais ou dados pessoais em Issues.

Use **Security advisories / Report a vulnerability** para um relato privado. Inclua impacto, versão, reprodução mínima e possível correção. Não acesse dados de terceiros durante testes.

Segredos expostos devem ser revogados e substituídos; apagá-los do código não os torna seguros novamente.
